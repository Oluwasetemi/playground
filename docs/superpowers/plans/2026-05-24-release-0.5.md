# v0.5.0 Release Plan

**Goal:** Ship the accumulated improvements from the Vite 8/Rolldown migration, URL bar, console forwarder refactor, terminal fixes, hot reload, and four new templates.

**Target versions:**
- `@setemiojo/playground-core` → `0.5.0`
- `@setemiojo/playground-react` → `0.5.0`
- `@setemiojo/playground-templates` → `0.4.0`

---

## What's in this release

### Breaking / infra

- **Vite 8 + Rolldown**: All three packages now build with Vite 8. Deprecated `manualChunks` function form replaced with `codeSplitting.groups`. Minifier switched from `esbuild` to OXC (`minify: true`).
- **Console forwarder pre-embedded**: The `CONSOLE_FORWARDER_SCRIPT` is now baked into each template's `index.html` at definition time (single source of truth in `packages/templates/src/console-forwarder.ts`). Runtime injection from `FileSystemManager` and `PreviewServer` has been removed entirely.

### New features

- **URL bar in PlaygroundPanel**: Status dot, editable URL input, refresh and external-link buttons. Syncs with `previewUrl`; disabled until `status === 'ready'`.
- **Hot reload for Node/Hono backends**: `node --watch server.js` in the Hono template's dev script restarts the process on file change and re-fires `server-ready`.
- **Four new templates**:
  - `react-eslint` — React 19 + `@setemiojo/eslint-config` (flat config, `eslint .` script)
  - `vue-eslint` — Vue 3 + `@setemiojo/eslint-config` (flat config, `eslint .` script)
  - `solid` — SolidJS 1.9 + `vite-plugin-solid`
  - `svelte` — Svelte 5 + `@sveltejs/vite-plugin-svelte`, uses `$state` rune and `mount()` API

### Bug fixes

- **Terminal whitespace gaps**: ANSI cursor-movement sequences (used by Vite's status-line updater) are stripped before writing to xterm.js. SGR color codes are preserved.
- **RAF cancel on Terminal unmount**: `cancelAnimationFrame(rafId)` prevents stale `fitAddon.fit()` calls firing after the component disposes.
- **Preview stop in cleanup**: `PlaygroundEngine.cleanup()` now calls `await this.preview?.stop()` before `webcontainerManager.teardown()`, preventing orphaned Vite processes.
- **Terminal messages cleared on reset**: `resetCode()` now clears both `consoleMessages` and `terminalMessages`.

## Known non-issues (document, don't fix)

- **Monaco chunk sizes**: `editor.main`, `standaloneServices`, and `react` chunks exceed 500 kB. These are Monaco/React externals that are expected to be large; the chunk size warning is cosmetic.
- **Svelte/Solid `.vue` fallback**: `.svelte` and `.jsx` (Solid) files open in the CodeMirror JS parser since `@codemirror/lang-svelte` and `@codemirror/lang-solid` aren't packaged. Syntax highlighting works well enough with the JS parser.
- **ESLint templates need npm install**: The `react-eslint` and `vue-eslint` templates install `@setemiojo/eslint-config` from npm, which is a larger install footprint. TemplateCache deduplicates installs on repeated switches.
